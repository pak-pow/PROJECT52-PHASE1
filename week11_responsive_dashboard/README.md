# Week 11: Responsive Dashboard

**Category:** Frontend | **Status:** Completed

## About

This project is a pure CSS challenge. The goal was to build a complete admin-style dashboard layout that adapts fluidly between mobile, tablet, and desktop screen sizes — using only HTML and CSS, with no JavaScript and no frameworks.

A dashboard is one of the most layout-intensive UI patterns: it combines a sidebar, a top navigation bar, metric cards, data tables, and content grids all on a single page. Getting this to collapse gracefully on mobile while remaining full-featured on desktop is a demanding exercise in CSS Grid and Flexbox mastery.

## What It Does

A fully responsive admin dashboard UI that adapts to any screen size. Includes a collapsible sidebar layout, metric summary cards, and a content grid — built entirely with CSS Grid and Flexbox.

## Learning Objectives

- CSS Grid for complex two-dimensional page layouts
- Flexbox for one-dimensional component alignment
- Responsive design with media queries for mobile, tablet, and desktop
- Building production-quality UI layouts without any JavaScript or framework
