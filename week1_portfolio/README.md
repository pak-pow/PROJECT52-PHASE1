# Week 1: Personal Portfolio

**Category:** Frontend | **Status:** Completed

## About

The very first project of Project 52. This is a personal portfolio website — the public face of the developer behind all 52 projects. The goal was not just to build something functional but to establish a baseline for HTML structure, CSS layout, and multi-page navigation before any JavaScript or backend work began.

The site consists of two pages: a home page (`index.html`) and an about page (`about.html`), with all styling centralized in `styles/style.css`. The `assests/` directory holds images and any static media used across both pages.

## What It Does

A two-page personal portfolio website presenting the developer's identity, skills, and project roadmap.

## Learning Objectives

- Structuring a multi-page website with consistent navigation
- CSS layout fundamentals: positioning, flexbox, and the box model
- Organizing a project with a dedicated styles directory and assets folder
- Writing clean, semantic HTML5

## Project Structure

```
week1_portfolio/
├── index.html          # Home page
├── about.html          # About page
├── styles/
│   └── style.css       # Shared stylesheet
└── assests/            # Images and static media
```

## Tech Stack

- **Frontend:** HTML5, CSS3
