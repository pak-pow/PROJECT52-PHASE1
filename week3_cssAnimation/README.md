# Week 3: CSS Animation Showcase

**Category:** Frontend | **Status:** Completed

## About

CSS is not just for layout. This project is a dedicated deep-dive into the CSS animation and transition system — one of the most underestimated and powerful tools in a frontend developer's kit.

The entire project lives in two files: `index.html` and `style.css`. The CSS file, at over 20KB, is the heart of this project — containing keyframe animations, transition timing functions, transform chains, and hover effects. The focus was on understanding how the browser renders motion and how to create smooth, performant animations without a single line of JavaScript.

## What It Does

A collection of CSS animations and transitions demonstrating the full range of what is possible with pure CSS: keyframes, transforms, transitions, and complex multi-step sequences.

## Learning Objectives

- Writing `@keyframes` animation sequences
- Understanding CSS `transform` properties: `translate`, `rotate`, `scale`, `skew`
- Timing functions and easing curves (`ease`, `ease-in-out`, `cubic-bezier`)
- Creating hover-triggered transitions and animation states
- Building performant animations that run on the GPU (using `transform` and `opacity`)
